## 📝 Tentang Praktikum

Repository ini berisi kumpulan **materi, modul, dan tugas praktikum** untuk mata kuliah **Konsep Pemrograman** menggunakan bahasa **C**. Materi disusun bertahap — dari dasar sintaks hingga struktur data sederhana — untuk mendukung proses belajar mahasiswa Informatika UNS.

<details>
<summary>📚 <b>Lihat cakupan materi</b></summary>
<br>

- Pengenalan & instalasi environment C
- Tipe data, variabel, dan operator
- Percabangan (`if-else`, `switch`)
- Perulangan (`for`, `while`, `do-while`)
- Array & String
- Fungsi & rekursi
- Pointer
- Struct sederhana

</details>
